## 🧾 Writeup Format

Each writeup follows the same structure so it's easy to follow:

1. **🎯 Overview** – what the room is about and the skills it covers
2. **🔍 Enumeration** – scanning and information gathering
3. **💥 Exploitation** – getting an initial foothold
4. **⬆️ Privilege Escalation** – going from user to root
5. **🚩 Flags** – how each flag was found
6. **🧠 Lessons Learned** – key takeaways and mistakes
